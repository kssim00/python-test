## v42 (2026-07-29) — 1급 문제 설명·정답 전수 재검증 (2차/2차 회차 포함 60문제 전체)
- **문제 설명(desc) 누락 내용 복원**
  - 4차 3번(스키장 최소 비용): 매개변수 설명에서 `one_day_price는 1일 이용권의 가격을 나타냅니다`, `multi_day_price는 multi_day일 이용권의 가격을 나타냅니다` 두 줄이 빠져 있던 것 복원
  - 4차 7번(몬스터·전사·힐러): monster_attack_point/warrior_attack_point/healing_point 세 매개변수 설명이 "모두 1 이상 500 이하의 자연수입니다" 한 줄로 요약되어 있던 것을 원문대로 세 줄로 복원
  - L·M·N(나머지)·O·P·Q 세트 전체 60문제를 원본 description.txt와 대조해 이 두 건 외에는 누락/요약이 없음을 확인
- **빈칸(@@@)과 정답 코드의 구조 불일치 수정**
  - 4차 5번(뒤집어 만드는 n번째 수): 문제의 빈칸이 `answer = answer[@@@]`(슬라이스 형태)인데 정답은 `answer = reverse(answer)` + 별도 `reverse()` 헬퍼 함수를 새로 정의해 빈칸 모양과 전혀 안 맞았음 → `answer = answer[::-1]`로 교체, 불필요한 헬퍼 함수 삭제. 실행 검증 완료(n=5 → "53124")
  - 나머지 1급 빈칸 채우기 문제 전체에서 같은 유형의 불일치는 없음을 확인
- **클래스/인터페이스 문제의 상위 메뉴 항목 누락 수정**: 여러 클래스를 설명하는 문제에서 `* ClassName :`(상위 메뉴 항목)이 그 클래스의 첫 번째 하위 설명 줄과 합쳐지면서 상위 메뉴 자체가 사라져 있던 문제 발견
  - 4차 7번(몬스터·전사·힐러): Unit/Monster/Warrior/Healer 네 클래스 모두 상위 메뉴 항목 복원
  - 3차 10번(미용실·레스토랑 예약): Customer/Shop/HairShop/Restaurant 네 클래스가 상위 메뉴 없이 한 문장으로 뭉쳐 있던 것을 원문 구조(상위 항목 + 하위 bullet)로 복원
  - 1차 1번, 2차 1번, 5차·6차 10번은 이미 올바른 구조였음(수정 없음)
- **4차 7번 문제 서술 보완**
  - "몬스터가 전사와 힐러를 한 번씩 공격했습니다" 등 세 가지 행동 설명이 서술형 문장으로 뭉쳐 있던 것을 원문대로 bullet 목록으로 복원
  - 예시 설명 표의 순서/수치가 뒤바뀌어 있던 것을 원문 순서(몬스터 공격 → 전사 공격 → 힐러 회복, 체력 1000/900/900 → 910/900/900 → 940/930/900)로 재작성
  - 표 렌더링 버그 수정: 예시 설명(note)이 `<table`로 시작하지 않으면 HTML로 렌더링되지 않고 태그가 그대로 텍스트로 노출되는 문제를 발견 — 표 앞뒤 설명 문구를 표 안의 행(colspan)으로 옮겨 정상 렌더링되도록 수정

    (공식 정답 파일 자체에 있던 오래된 불일치였음, starter 기준으로 통일)
